# Memoized Version of calc_foragecapture

A memoized version of [`calc_foragecapture`](calc_foragecapture.md)
using [`memoise`](https://memoise.r-lib.org/reference/memoise.html).
This version caches results for improved performance on repeated calls
with the same arguments.

## Usage

``` r
memoised_calc_foragecapture(...)
```
