# SPA Site List Dataset

This dataset contains information about Special Protection Areas (SPAs),
including site codes, site names.

## Usage

``` r
spalist
```

## Format

A data frame with the following 10 columns:

- SITE_CODE:

  Character: A unique code identifying each SPA.

- SITE_NAME:

  Character: The name of the SPA.

- CEF.include:

  character: Indicates if the site is included in the CEF project (Y) or
  not (NA).

- Marine.only:

  character: Indicates if the site is classified as a marine-only SPA.

- Altnames.sufficient:

  character:NEED EXPL

- Altnames.SPApolys:

  character:NEED EXPL

- Altnames.SMP:

  character:NEED EXPL

- Altnames.Productivity:

  character:NEED EXPL

- Altnames.BDMPS:

  character:NEED EXPL

- Altnames.FR:

  character:NEED EXPL.
