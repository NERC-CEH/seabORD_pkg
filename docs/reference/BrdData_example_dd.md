# BrdData_example_dd

NEED EXPL

## Usage

``` r
BrdData_example_dd
```

## Format

list of "raster" with the values of a raster in a matrix; and "metadata"
with the extent and resolution to build back the raster in memory.

- matrix:

  matrix of pixel values

- metadata:

  List of metadata: extent, resolution, and CRS.
